# S21

Fitting routines for the microwave cavity transmission parameter $S_{21}$.

The cavity model is:

$$
S_{21}(f) = \left| \frac{2\pi\kappa_\text{ext}}{2\pi\kappa_\text{tot} + 4\pi i(f - f_0)} \right| + \text{background}
$$

Fit parameters returned as `popt = [f_0, κ_tot, κ_ext, slope, offset]`.
