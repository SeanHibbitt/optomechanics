# GUI

The `optomechanics.GUI` subpackage provides a PyQt5 graphical interface for
temperature readout and PID control of cryogenic systems.

!!! warning "Experimental"
    This subpackage contains known bugs and is not production-ready.
    See the [Temperature Control GUI](../../user_guide/gui_temperature_control.md)
    user guide for details.
