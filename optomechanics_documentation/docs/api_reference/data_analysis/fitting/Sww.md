# Sww

Noise power spectral density ($S_{ww}$) fitting and normalisation routines.

Includes the `fit_S_xx` class for full pipeline normalisation
(S21 fitting → photon number → $G^2 S_{xx}$), and standalone functions
for fitting the basic Lorentzian PSD model.
